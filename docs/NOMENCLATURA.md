# Nomes do projeto

O projeto e seu chatbot se chamam **Nexus**. O jogo se chama **Nexus Run**. Esses nomes são usados na interface, nos créditos, na base de conhecimento, nas instruções Gemini e na apresentação narrada local.

Para preservar os dados existentes, o banco continua se chamando `mannequin_run`; os identificadores de armazenamento do navegador e o formato dos backups também foram mantidos. Não é necessário recriar perfis ou migrar recordes por causa da mudança de nome.

O nome técnico do repositório e o endereço atual do GitHub Pages permanecem os mesmos: https://0matheus-silva.github.io/Mannequin-Run/. A mudança de marca não exige renomear o repositório.
